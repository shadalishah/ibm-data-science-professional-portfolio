## About This Repository

This repository contains the applied projects and capstone work completed as part of the **IBM Data Science Professional Certificate**. It demonstrates hands-on, end-to-end data science skills — from data collection and SQL querying to exploratory analysis, machine learning, and interactive dashboards — applied across real-world datasets including SpaceX launch data, Australian weather records, and stock/revenue data.

Each folder below corresponds to a course module in the certificate and contains a self-contained project.

---

## Highlighted Project: SpaceX Falcon 9 Landing Prediction (Capstone)

**Folder:** `Applied_Data_Science_Capstone/`

A full data science pipeline predicting whether the SpaceX Falcon 9 first-stage booster will land successfully — directly mirroring how SpaceX's cost advantage over competitors (~$62M vs $165M+ per launch) depends on reusability.

| Stage | What Was Done |
|---|---|
| Data Collection | Web scraping and REST API calls to gather launch records |
| Data Wrangling | Cleaning and structuring raw launch data (`Spacex.csv`) |
| Exploratory Data Analysis | Visual analysis of launch site, payload, and orbit patterns (`edadataviz.ipynb`) |
| Geospatial Analysis | Mapping launch site locations (`lab_jupyter_launch_site_location.ipynb`) |
| Machine Learning | Classification models (Logistic Regression, SVM, Decision Tree, KNN) to predict landing success (`SpaceX_Machine Learning Prediction_Part_5.ipynb`) |

**Skills demonstrated:** data collection, feature engineering, classification modeling, model evaluation, data visualization.
